# 3x2 collage grid spec

Shared by `doodle-collage` (close-up) and `full-body-collage` (head to toe).

## Canvas

- One single image, landscape, 3:2 aspect ratio.
- Exactly 3 columns by 2 rows = 6 panels. Never 4, never 8.
- Thin, hand-drawn panel borders — slightly uneven, not ruler-straight.

## Panel variety

Each panel is the same character in a different moment. Vary along these
axes so the six panels never read as duplicates:

| Axis       | Vary it by                                               |
| ---------- | -------------------------------------------------------- |
| Expression | laughing, thoughtful, surprised, calm, mischievous, shy   |
| Angle      | straight on, three-quarter, profile, slight overhead      |
| Crop       | tight face, head and shoulders, chest up                  |
| Gesture    | hand near face, waving, arms crossed, leaning             |

Keep hairstyle, face shape, skin tone, and outfit identical across all six.
That consistency is what makes the grid read as one character rather than
six different people.

## Overlay doodles

Loose hand-drawn marks that cross panel borders and unify the page:

- motion lines trailing gestures
- sparkles and small stars near happy expressions
- squiggles, dots, and dashes filling dead space
- the occasional small heart or exclamation mark

Keep overlays sparse enough that the character stays the focus. If a user
asks for something "cleaner", drop the overlays first.
