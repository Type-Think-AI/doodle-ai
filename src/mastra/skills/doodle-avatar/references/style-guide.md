# Doodle AI house style

The shared visual language behind every Doodle AI skill. Read this when a
user asks *why* a doodle looks the way it does, or asks for a refinement and
you need to know which knobs exist.

## Core rules

| Attribute   | Target                                                     |
| ----------- | ---------------------------------------------------------- |
| Line        | Bold, clean, confident outlines with slight wobble          |
| Detail      | Simplified — suggest features, never render them            |
| Color       | Flat and cheerful, minimal shading, no gradients            |
| Proportion  | Playful and slightly exaggerated, chibi-leaning             |
| Background  | Clean white or warm white, uncluttered                      |
| Texture     | Marker, ink, or dry-brush edges where it adds life          |

## Always avoid

- Photorealism, 3D renders, or heavy cinematic shading
- Text, captions, watermarks, or signatures in the image
- Cluttered backgrounds that compete with the subject
- Losing the person's recognizable features in stylization

## What must stay recognizable

When a photo is the source, these carry the likeness and must survive the
translation to illustration:

1. Hairstyle silhouette and hair color
2. Face shape and skin tone
3. Expression
4. Glasses and distinctive accessories
5. Outfit color story (for full-body work)

## Refinement vocabulary

Users often ask for changes in loose terms. Map them to these adjustments:

- "thicker outline" / "bolder" → increase line weight, reduce interior detail
- "warmer paper" → shift the background toward warm white or cream
- "cuter" / "more chibi" → larger head-to-body ratio, softer shapes
- "cleaner" → remove overlay doodles and background props
- "more colorful" → widen the palette, keep colors flat
