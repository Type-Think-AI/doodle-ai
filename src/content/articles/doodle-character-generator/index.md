**Direct answer:** The doodle character generator at [doodleai.art](https://doodleai.art) draws a fictional character from a description — no photo needed. Sign in with Google, describe the character in the box above, and run the [Surprise skill](https://doodleai.art/skills/surprise/). Each character costs 1 credit and refunds on failure; new accounts get free starter credits.

This one flips the usual flow. Most tools here start from your photo, but a character generator starts from your imagination. You write who the character is, and the Surprise skill invents a doodle to match — no camera roll involved.

## Describe, don't upload

Because there is no photo, your words do all the steering. Name the essentials — what it is, a couple of standout features, a vibe — and the Surprise skill draws a square doodle in the house style: bold outlines, flat color, warm-white background. It is invention, not likeness, so treat each run as a fresh take.

## A description to start with

> A grumpy little robot barista with one big eye and a tiny apron, holding a coffee cup. Doodle style, flat color, warm-white background, no text.

Concrete nouns and one clear mood beat a long lore dump.

## Questions people ask

**Do I need a photo?** No — the character generator uses the [Surprise skill](https://doodleai.art/skills/surprise/), which draws from text. Describe it and sign in.

**Is it free?** Free browsing and free starter credits, then 1 credit each, refunded on failure. No paywall.

**How detailed should my description be?** A few concrete traits — species or role, one or two features, a mood.

**Will the same description always give the same character?** No — it is generative; run it a few times and keep your favorite.

**Can I turn a real person into a character?** For a real face, use the photo-based [Normal skill](https://doodleai.art/skills/normal/) instead.
