**Direct answer:** To make a doodle icon at [doodleai.art](https://doodleai.art), sign in, attach a photo or describe an idea, and run the [Normal skill](https://doodleai.art/skills/normal/) (or [Surprise](https://doodleai.art/skills/surprise/) for a made-up one) asking for a simple, centered icon-style doodle. You get one square hand-drawn doodle. Each run is 1 credit and refunds on failure; new accounts get free starter credits.

A "doodle icon" here is a simple square doodle you can use as an icon or avatar — from your photo or from an idea. This is not a new icon-design engine; it is the same doodle generator, framed for clean, small-readable output.

## A doodle, framed as an icon

The [Normal skill](https://doodleai.art/skills/normal/) redraws a photo into a hand-drawn doodle; [Surprise](https://doodleai.art/skills/surprise/) invents one from a prompt. For an icon, ask for one clear centered subject, bold outlines, minimal detail, and a plain background so it reads at small sizes.

## Prompt for icon-style output

> Make a simple doodle icon. One centered subject, bold outlines, minimal detail, flat color, plain background. No text.

Icons read small, so strong shapes beat fine detail.

## Not an icon engine

There is no SVG export, no icon set, no multi-resolution output. You get one square PNG-style doodle. Resize or crop it yourself for the slot you need.
