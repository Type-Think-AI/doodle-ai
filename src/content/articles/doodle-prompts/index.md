**Direct answer:** Doodle prompts at [doodleai.art](https://doodleai.art) are short descriptions the Surprise skill turns into fictional doodles — no photo needed. Sign in with Google, type a prompt in the box above, and run the [Surprise skill](https://doodleai.art/skills/surprise/). A good prompt is a nudge, not a novel. Name the subject, add a feature or two, set a mood, and the Surprise skill invents a doodle in the house style: bold outlines, flat color, warm-white background.

## Prompt patterns to try

- A subject plus a mood: "A grumpy cat wearing a tiny crown, regal."
- An object with a twist: "A teapot with legs, out for a walk."
- A simple scene: "A little astronaut planting a flower on a small planet."

Keep each concrete and short. Add "doodle style, flat color, warm-white background, no text" to lock the look.
