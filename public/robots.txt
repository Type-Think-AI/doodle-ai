# AI crawlers and answer engines.
#
# The blanket `User-agent: *` block above already allows all of these, so these
# groups are not what grants access — they are here so that allowing or blocking
# any single agent later is a one-line edit against a named group, instead of a
# guess about which token that vendor reads.
#
# Two of these are training-scope controls rather than crawlers, and are named
# explicitly because their default is the opposite of the others:
#   Google-Extended   — Gemini training / grounding. Does not affect Search.
#   Applebot-Extended — Apple Intelligence training. Does not affect Siri/Spotlight.
#
# Each group repeats the Disallow list, because a robots.txt group does NOT
# inherit rules from `*` — an agent matching its own group ignores `*` entirely,
# so omitting these lines here would expose /api/ and the account-scoped routes
# to every agent named below.
# ---------------------------------------------------------------------------
